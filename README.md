# ShopDesk

A small product-management dashboard app

## Tech stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ESLint
- Prettier

## Prerequisites

- Node.js LTS
- npm
- Git

## Installation

```bash
git clone https://github.com/bakiurtech/ur-frontend-training.git
cd ur-frontend-training
npm install
```

## Run the project

```bash
npm run dev      # dev server at http://localhost:3000
npm run build    # production build
npm run lint     # run ESLint
npm run format   # format code with Prettier
```
